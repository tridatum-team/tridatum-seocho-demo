# 공개 출처와 합성 문서의 이용 범위

- HL홀딩스 공개 사업소개·지속가능경영보고서: 부품유통, OCR 활용, 반품·클레임의 업무 맥락 참고.
- 강원종합기술연구원: https://kiit.kr/bbs/board.php?bo_table=lab_bbs2&wr_id=44 — 납품·검사·검수의 날짜·담당·품목 구분 참고.
- 세종시시설관리공단: https://www.sjfmc.or.kr/download/viewer/1553843301451/index.html — 계약·전회 납품·금회 납품·잔량의 항목 구조 참고.

기관 원문은 포함하거나 재배포하지 않습니다. 실제 인명·연락처·사업자번호·실제 거래·기관 로고·날인·법조문을 복제하지 않고 독립적으로 합성 문서를 작성했습니다. 샘플의 example.com 주소는 합성 연락처입니다.

현재·과거 규정의 14일·30일은 시연용 가상 반품 기준이며 기관의 검사기한 또는 HL의 실제 규정이 아닙니다. 추가된 납품·검수 항목은 담당자 열람용이며 자동 수량 계산의 근거는 거래 CSV입니다.

구체적인 출처와 문서별 참조 ID는 `sources.json`, `../data/bundles.json`에 있습니다. 평가 정답과 생성용 원천 데이터는 운영 웹의 정적 자산으로 배포하지 않습니다.
